            Keys: Space play/pause · ←/→ nudge selected beat(s) ±20 ms (Shift ±100 ms) · A select all beats after playhead (or, with an event selected, all following events of that kind) · T add structure · S add section · C add chord · B add beat · R copy sections→structure · D double beats · H halve beats · 2/3/4 subdivide gaps between selected beats · Del delete selected · Esc deselect · Q/E jump back/forward N bars · J/K prev/next section · Ctrl+Z undo · Ctrl+S save · Ctrl+D toggle downbeat (selected beats) · Alt+C insert chords (selected section) · Ctrl+C/Ctrl+V copy & paste selected chords (pasted from the beat nearest the playhead) · Tab in the chord-name box steps to the next chord (Shift+Tab previous) · ◀◀/▶▶ jump the playhead by N bars · Mouse wheel to zoom · Alt+wheel to scroll horizontally · Drag the ruler to scrub (drag past an edge to auto-scroll) · Double-click-drag the ruler for a loop region (selects the beats inside; double-click elsewhere to clear) · Shift-click beats to multi-select (or chords, for a range) · drag any selected beat to move the group · Fill ×4 subdivides gaps between selected beats · Click waveform to seek (and deselect) · Downbeats are amber (toggle in the inspector, or add a section to auto-grid every 4th).
